Roles & Jobs to be Done

Who logs in, what each person needs to accomplish, and how that job is done today. Built around tasks, not screens.

How to read this. This is deliberately written as jobs-to-be-done, not screens or modules. We're not asking for a "sourcing screen." We're describing what each person needs to accomplish, and how they do it today. You design the interface around the jobs. Full written PRD: system-prd.md.
